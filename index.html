Excel 批量合并

有个客户说50家分店的日报表，每次汇总要搞半天。我写了个小脚本，选文件夹点一下，3秒合成一张总表。

# 核心就 20 行
import pandas as pd
import glob
files = glob.glob("*.xlsx")
result = pd.concat([
    pd.read_excel(f) for f in files
])
result.to_excel("合并结果.xlsx")
