Excel

Excel 批量合并工具

把多个Excel文件自动合并成一个，支持xlsx/xls格式。自动添加来源标记，方便追溯数据。

import pandas as pd
import glob

files = glob.glob("*.xlsx")
all_data = []
for f in files:
    df = pd.read_excel(f)
    df['来源'] = f
    all_data.append(df)

result = pd.concat(all_data, ignore_index=True)
result.to_excel("合并结果.xlsx", index=False)

适用场景：月报汇总、多店数据合并、部门报表整合

网页数据采集器

从目标网站批量采集公开数据，支持分页、自动识别编码、导出Excel。

import requests
from bs4 import BeautifulSoup

def fetch_page(url):
    headers = {"User-Agent": "Mozilla/5.0"}
    resp = requests.get(url, headers=headers, timeout=10)
    return resp.text

def parse_data(html):
    soup = BeautifulSoup(html, 'html.parser')
    # 根据目标网页结构调整选择器
    items = soup.select('.item')
    return [item.get_text(strip=True) for item in items]

自动化

批量文件重命名工具

带图形界面的批量重命名工具，支持多种命名规则，预览后再执行，安全可靠。

import os

folder = "./photos"
for i, fname in enumerate(os.listdir(folder), 1):
    ext = os.path.splitext(fname)[1]
    new_name = f"照片_{i:03d}{ext}"
    os.rename(
        os.path.join(folder, fname),
        os.path.join(folder, new_name)
    )
